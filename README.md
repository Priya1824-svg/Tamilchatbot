# 🤖 தமிழ் சாட்பாட் (Tamil Chatbot)

An NLP-based chatbot that converses in both Tamil and English languages.

## 💡 Features
- Responds in Tamil and English
- Understands greetings, questions about AI, NLP, ML in Tamil
- Built using rule-based NLP with pattern matching
- Clean chat interface with example prompts

## 🛠️ Technologies Used
- Python
- NLTK
- Gradio (Web Interface)
- Google Colab (CPU)

## 🔗 Connection to Research
This project is directly inspired by my IEEE research paper on
NLP-based phonetic insights for Tamil language processing.
